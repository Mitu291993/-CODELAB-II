Programming Skills Portfolio – CodeLab II

This repository contains my three C++ coding challenges for CodeLab II. Each challenge helped me practise different programming skills and improve my understanding of C++.

Challenge 1 – CO₂ Calculator

A simple program that calculates estimated CO₂ emissions from a car journey based on the distance travelled and whether the car uses petrol or diesel.

Challenge 2 – Alexa Joke Generator

This program reads jokes from a text file and picks one randomly. It shows the first part of the joke and waits for the user to press Enter before showing the punchline.

Challenge 3 – Book Manager

A basic library system where users can view books, search for a book by ID, and borrow or return books. The program saves changes to a text file.

How to Run

Each challenge has its own C++ program. Compile and run the programs using a C++ compiler. For challenges 2 and 3, make sure the required text files are in the correct working folder.
